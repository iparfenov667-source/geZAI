# 📜 Договорник — генератор договоров из Word-шаблона

Веб-приложение, которое превращает любой `.docx`-шаблон в генератор договоров:
загружаете свой файл Word с плейсхолдерами вида `{тег}` → заполняете форму →
скачиваете готовый документ `.docx` (или все договоры сразу архивом `.zip`).

Всё работает локально в браузере: файлы никуда не отправляются.

## Возможности

- 📥 **Загрузка шаблона** — drag&drop или выбор `.docx` (старый `.doc` и другие форматы отклоняются с подсказкой)
- 🔍 **Автоизвлечение полей** — все `{фигурные_скобки}` документа становятся полями формы, даже если Word разбил тег на несколько фрагментов
- 👀 **Живое превью** — лист A4 обновляется по мере ввода, с зумом
- 🗂 **Несколько записей** — копии договора на разных контрагентов, скачивание всех одним ZIP
- 💾 **Автосохранение** — шаблон и записи переживают перезагрузку страницы (localStorage)
- 🖨 **Демо-шаблон** — встроенный пример договора оказания услуг с 13 полями

## Как пользоваться шаблоном

1. В Word расставьте плейсхолдеры: `Договор № {номер_договора} от {дата}`, `{заказчик_фио}`, `{сумма}` и т.д.
2. Сохраните как `.docx`.
3. Загрузите в приложение, заполните форму, нажмите **«Скачать .docx»**.

Оформление исходного шаблона (шрифты, таблицы, колонтитулы) сохраняется.

## Запуск локально

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # production-сборка в dist/
npm run typecheck  # проверка типов
```

## Автодеплой на GitHub Pages

В репозитории уже настроен workflow `.github/workflows/deploy.yml`:
при каждом пуше в `main` приложение собирается и публикуется на GitHub Pages.

После первого пуша включите в настройках репозитория:
**Settings → Pages → Source → GitHub Actions** — сайт появится по адресу
`https://ВАШ_ЛОГИН.github.io/ВАШ_РЕПОЗИТОРИЙ/`.

## Технологии

| Слой | Инструмент |
|---|---|
| UI | React 18 + TypeScript, Tailwind CSS 4, lucide-react |
| Сборка | Vite 6 |
| Работа с .docx | docxtemplater + PizZip (разбор и заполнение), mammoth (HTML-превью) |

## Структура

```

├── components/
│   ├── Dropzone.tsx         # drag&drop-зона
│   ├── FieldForm.tsx        # форма полей шаблона

│   ├── PreviewPane.tsx      # превью A4 с зумом
│   └── Toasts.tsx           # уведомления
```
